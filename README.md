# VisionGuard — AI vs Real Image Classification

[![VisionGuard CI](https://github.com/Wasara-Tehzeeb/23L-0749_A2_Ops/actions/workflows/visionguard-ci.yml/badge.svg)](https://github.com/Wasara-Tehzeeb/23L-0749_A2_Ops/actions/workflows/visionguard-ci.yml)

VisionGuard is a machine learning application that classifies uploaded images as AI-generated or real.

## Features

- AI-generated vs real image classification
- Flask web application
- Prediction history
- Docker deployment
- MLflow experiment tracking
- Automated testing and Docker builds using GitHub Actions
